# N-Path Receiver

This project models and evaluates an N-path receiver architecture against a conventional receiver in the presence of an out-of-band interferer. The code generates OFDM-like passband signals, runs both receiver chains through filtering and soft-saturation, and calculates achievable rate as a function of SNR and INR.

The implementation is organized as a small Python package under `npath/` and a notebook workflow in `run.ipynb` that exercises the end-to-end simulation and saves the results.

## What the package does

- Generates a desired signal and interferer using OFDM-style QPSK symbols and carrier up-conversion.
- Simulates an N-path receiver with time-interleaved switching, RC filtering, and a nonlinear soft-saturation stage.
- Simulates a conventional receiver with a baseline down-conversion and filtering chain.
- Quantizes the ADC output and computes achievable rate using frequency-domain correlation.
- Saves sweep results to CSV and produces plots for spectrum and rate comparisons.

## Repository layout

- `npath/__init__.py` — package exports
- `npath/npathrx.py` — signal generation and receiver classes
- `npath/utilities.py` — FFT helpers and signal-processing utilities
- `npath/plot.py` — plotting helpers for PSD and rate curves
- `npath/test.py` — end-to-end sweep/test harness
- `run.ipynb` — notebook workflow for signal spectrum and rate sweeps
- `results/data/` — generated CSV outputs from the simulations
- `results/plots/` — generated plots

## Core API

### Signal generation

```python
from npath import SignalGenerator

sig = SignalGenerator(f_p1=8e9,
                      f_p2=13e9,
                      f_s=32e9,
                      bw_ofdm=100e6,
                      Nfft=512,
                      Nsamp=50,
                      Nrep=3,
                      symmetry=True)

t, x_b1, x_b2, x_p1, x_p2 = sig.generate(snr_db=20, inr_db=20, noise_db=0)
```

This returns:

- `t`: time vector
- `x_b1`: desired baseband signal
- `x_b2`: interferer baseband signal
- `x_p1`: desired passband signal
- `x_p2`: interferer passband signal

### Receiver simulation

```python
from npath import NPathRX

rx = NPathRX(f_lo=8e9,
             f_adc=400e6,
             N=4,
             f_s=32e9,
             f_c1=400e6,
             f_c2=400e6,
             noise_db=0,
             sat_db=40,
             baseband=True)

y_adc_q, y_conv_adc_q = rx.run(x_p1=x_p1, x_p2=x_p2, f_p1=8e9, f_p2=13e9)
```

This passes the desired and interferer passband signals through the N-path and conventional receiver chains and returns the ADC-rate quantized outputs.

### End-to-end evaluation

```python
import numpy as np
from npath import NPathRXTest, plot_rate

N = 4
f_p1 = 8e9
f_p2 = 10e9
f_s = N * f_p1
f_adc = 100e6

SNR_db = np.arange(0, 36, 5)
INR_db = np.arange(0, 81, 5)

test = NPathRXTest(N=N,
                   f_s=f_s,
                   f_p2=f_p2,
                   Nsamp=200,
                   f_c1=100e6,
                   f_c2=400e6,
                   symmetry=True,
                   f_adc=f_adc)

test.run(SNR_db, INR_db)
plot_rate("results/data/4_path_data.csv", n_rows=2)
```

This runs a SNR/INR sweep, saves the results to CSV, and plots achievable rate vs. INR for the N-path and conventional receivers.

## Utility functions

The package also exposes helpers for signal processing and analysis:

- `nfft(x)` and `nifft(X)`: unitary FFT/IFFT helpers
- `achievable_rate(x, y)`: computes an achievable rate estimate from input/output correlation
- `quantizer(y, delta, b=10)`: simple uniform complex quantizer
- `delta_backoff(y, b=10, backoff_db=12)`: chooses a quantizer step size using a power backoff rule

## Notebook workflow

The notebook at `run.ipynb` follows the same workflow as the Python API:

1. import the `npath` package
2. plot the spectrum of a representative signal and interferer case
3. run a sweep over SNR and INR values
4. save simulation results to `results/data/<N>_path_data.csv`
5. create plots in `results/plots/`

This is the easiest way to reproduce the project’s main figures.

## Example outputs

The project currently stores generated data and plots under `results/`. These files are generated by the notebook or by calling the `NPathRXTest.run()` method.
